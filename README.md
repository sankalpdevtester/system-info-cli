# System Information CLI Tool
A command-line tool that provides detailed information about a system's hardware and software configuration, useful for system administrators and developers.

## Features
- CPU information
- Memory information
- Disk information
- Network information
- Operating System information

## Installation
To use this tool, simply make the script executable with the following command:
```bash
chmod +x system_info.sh
```
Then, run the script with the following command:
```bash
./system_info.sh
```
## Usage
The tool will display the system information in the following format:
- CPU Information
  - Model
  - Number of Cores
  - CPU Frequency
- Memory Information
  - Total Memory
  - Used Memory
  - Available Memory
- Disk Information
  - Total Disk Space
  - Used Disk Space
  - Available Disk Space
- Network Information
  - IP Address
  - Hostname
- Operating System Information
  - OS Name
  - OS Version
